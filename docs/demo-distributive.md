# Дистрибутив Pulse: Руководство по развертыванию демонстрационного стенда

Это руководство подготовлено для быстрого развертывания и ознакомления с платформой **Pulse** (например, для демонстрации возможностей Институту).

---

## 1. Концепция демонстрационного стенда

Для простоты ознакомления и тестирования Pulse поставляется в виде готового **Docker-окружения** с преднастроенными демонстрационными данными (сидами).

Для полноценного показа **не требуется** разворачивать сторонний сервис авторизации (ACHPP ID SSO). Мы можем переключить систему в режим работы по логину и паролю.

---

## 2. Быстрый запуск через Docker Compose (Рекомендуется)

Это самый простой способ запустить систему на любом компьютере (Windows, macOS, Linux), где установлен **Docker Desktop**.

### Шаг 2.1. Подготовка кода и окружения

1. Клонируйте репозиторий с кодом Pulse или скопируйте архив с проектом в рабочий каталог.
2. В корневой директории проекта скопируйте пример файла конфигурации:
   ```bash
   cp .env.docker.example .env.docker
   ```
3. Убедитесь, что в файле `.env.docker` отключен обязательный вход через SSO, чтобы вы могли зайти по паролю:
   ```env
   PULSE_SSO_ONLY=false
   ```

### Шаг 2.2. Запуск контейнеров

В терминале в корне проекта выполните команду:
```bash
docker compose up -d
```
Docker скачает необходимые образы и запустит 5 связанных сервисов:
- `pulse-app` — PHP-FPM приложение
- `pulse-nginx` — веб-сервер (будет доступен по адресу `http://localhost:8080`)
- `pulse-postgres` — база данных PostgreSQL
- `pulse-redis` — кэш, очереди и брокер сообщений
- `pulse-reverb` — WebSocket-сервер для мгновенного обновления сообщений в реальном времени

### Шаг 2.3. Инициализация базы данных и сидирование

Выполните команды миграции базы данных и наполнения её тестовыми данными:
```bash
docker compose exec app php artisan migrate --force
docker compose exec app php artisan db:seed --force
```

Скрипты наполнения базы данных автоматически создадут:
1. **Тестовые источники обращений**: Сайт-виджет, Telegram-бот, группа ВКонтакте.
2. **10 базовых разделов (отделов) экосистемы**: АЧПП ID, Портал (Курсы, Оплата, Встречи), Аврора (Консультации, Звонки), Этика и жалобы, Прочие вопросы.
3. **Демонстрационных пользователей и чаты** с наполненной историей сообщений.

## 3. Демонстрационные учётные записи

После выполнения сидирования базы данных вы можете зайти под любым из следующих модераторов:

| Роль модератора | E-mail | Пароль | Доступные каналы и особенности |
|:---|:---|:---|:---|
| **Администратор** | `admin@pulse.example` | `password` | Полный доступ к панели Filament, видит абсолютно все чаты и источники |
| **Модератор А** | `anna@pulse.example` | `password` | Привязана к сайту АЧПП (`achpp_web`) и ВКонтакте, закреплена за узкими отделами |
| **Модератор Б** | `boris@pulse.example` | `password` | Привязан к Telegram-боту, закреплен за отделом техподдержки |

## 4. Точки входа в демонстрационном режиме

- **Главная панель администратора (Filament)**: `http://localhost:8080/admin`  
  *Здесь настраиваются источники, права доступа, редактируются разделы (отделы) и быстрые шаблоны ответов.*
- **Веб-панель модератора (Inbox)**: `http://localhost:8080/chat`  
  *Интерфейс для работы с обращениями в реальном времени.*
- **Тестовый виджет на сайте**: `http://localhost:8080/` (или страница, где подключен скрипт виджета).

## 5. Сценарий 15-минутной демонстрации (для АА и Института)

Чтобы показать, как Pulse автоматизирует поддержку и распределяет вопросы по рубрикам:

### Шаг 5.1. Показ административной панели
1. Откройте `http://localhost:8080/admin` и авторизуйтесь под `admin@pulse.example` / `password`.
2. Перейдите в **Интеграции → Источники**. Покажите, что заведены три площадки: Сайт, Telegram, ВКонтакте.
3. Перейдите в **Отделы** (Рубрики). Покажите список из 10 рубрик (Оплата, Мессенджер, Консультации Авроры и т.д.). Обратите внимание, что для каждого отдела можно включить или выключить автоматический AI-анализ.

### Шаг 5.2. Показ работы AI-рубрикатора и назначения чатов
1. Откройте веб-панель модератора в одной вкладке браузера: `http://localhost:8080/chat` (под пользователем `admin@pulse.example`).
2. В другой вкладке (или в режиме инкогнито) откройте демонстрационную страницу с виджетом `http://localhost:8080/` (или отправьте сообщение в настроенный Telegram-бот).
3. Напишите в виджет тестовое сообщение, симулирующее вопрос пользователя, например:  
   > *«Здравствуйте! Я оплатил подписку на портале АЧПП через Робокассу, но доступ к курсу по этике всё ещё закрыт. Помогите!»*
4. Нажмите «Отправить».
5. Вернитесь в панель модератора. Вы увидите:
   - Сообщение прилетело мгновенно без перезагрузки страницы (благодаря Laravel Reverb).
   - Фоновая нейросеть (AI-агент) автоматически проанализировала текст вопроса и назначила чату рубрику: **«Портал: подписки и оплата»** (или сформировала краткую тему диалога).
   - В зависимости от привязки модераторов к отделам, это обращение сразу появится в соответствующей вкладке (табе) нужного специалиста.

### Шаг 5.3. Использование Десктопного и Мобильного приложений
1. Запустите собранное десктопное приложение (`npm run desktop:dev` в корне проекта Pulse) или мобильный клиент.
2. Авторизуйтесь под `anna@pulse.example` или `admin@pulse.example`.
3. Покажите обновленный интерфейс инбокса:
   - Сверху отображаются **отделы (рубрики) в виде удобных табов** со счётчиками активных диалогов (например, "Все", "Аврора: консультации", "Портал: оплата").
   - Сбоку находится кнопка **Фильтры** (воронка), позволяющая мгновенно отфильтровать список по параметрам: *«Назначены на меня»*, *«Без ответственного»*, *«Непрочитанные»*, *«Новые»*.
   - Покажите, как модератор может «забрать чат себе» одной кнопкой, отправить быстрый шаблонный ответ или перевести чат на другой отдел (рубрику).

## 6. Применение платформы для Института

Благодаря гибкой структуре, Pulse идеально адаптируется под задачи Института. 

Для этого в панели администратора достаточно создать:
- Новый источник типа `web` (например, `institute_web` для сайта института).
- Свои собственные отделы (рубрики), например:
  - `Приёмная комиссия` (категория: `registration`)
  - `Учебный отдел и расписание` (категория: `support`)
  - `Оплата обучения и семестров` (категория: `support`)
  - `Студенческий совет и этика` (категория: `ethics`)
- Привязать соответствующих кураторов/модераторов к нужным отделам.
- Интегрировать виджет на сайт Института простым встраиванием JS-скрипта (одна строка).
